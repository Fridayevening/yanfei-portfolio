# Yanfei Portfolio

An interactive personal portfolio built with React, TypeScript, and Vite.

The landing page is an illustrated desktop: drag the character and folders, double-click a folder to browse project stories or research, and use the close button to return to the desktop.

## Development

```bash
npm install
npm run dev
```

Other checks:

```bash
npm run typecheck
npm run lint
npm run build
```

## Content

- `src/data/workStories.ts`: project stories and metrics.
- `public/research/`: research text files.
- `public/intro/`: desktop artwork and interaction assets.
- `public/works/`: project cover images.
